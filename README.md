# Calc Python

Command-line calculator supporting arithmetic, scientific, and unit conversion operations.

## Features

- Basic arithmetic operations
- Scientific functions (trigonometry, logarithms, exponents)
- Unit conversion support
- Expression history and recall
- Interactive REPL mode

## Tech Stack

Python, Math

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/karthik-idikuda/Calc-Python.git
cd Calc-Python
pip install -r requirements.txt
```

### Usage

```bash
python calc.py
```
